01 — Overview

Overview

Urban traffic signals that run on fixed timers can't respond to how traffic actually moves through an intersection at a given moment. This project set out to build a system that watches real traffic conditions and adapts signal timing accordingly — combining a computer vision pipeline for reading the road with a multi-agent reinforcement learning policy for deciding what to do about it.

The system was built and evaluated using SUMO (Simulation of Urban Mobility), with signal-control agents coordinating across intersections rather than acting independently.

02 — The Challenge

The challenge

Traffic congestion at signalized intersections is a coordination problem, not just a timing problem. A single intersection reacting only to its own queue can create or worsen congestion at the next one. Adaptive control needs to account for what's happening across a network of connected intersections, prioritize emergency vehicles when they appear, and still make decisions fast enough to be useful in real time.

That combination — multi-agent coordination, emergency vehicle priority, and real-time computer vision input — is what shaped the system's architecture.

04 — My Contribution

My contribution

This was a team project. My specific contribution was the computer vision pipeline, system integration, and the deployment/operator platform — not every component of the system end to end.

Concretely, that meant building the vehicle detection and tracking pipeline with YOLOv8 and BoT-SORT, wiring that pipeline's output into the rest of the system so traffic statistics could feed the simulation and control layers, and building the operator-facing platform using FastAPI on the backend and PyQt5 for the desktop interface — giving an operator visibility into the system and the ability to manually override signals when needed.
