Twitter Sentiment Analysis

01 — Overview

Overview

This project compares four neural network architectures — a feedforward network (FFNN), a plain recurrent network (RNN), an LSTM, and a GRU — on the same binary sentiment classification task, trained under the same conditions so the comparison is meaningful.

The dataset is NLTK's twitter_samples corpus: 5,000 positive and 5,000 negative tweets, 10,000 total.

02 — The Challenge

The challenge

It's easy to find claims that one architecture "beats" another, but those comparisons often use different hyperparameters, different splits, or different stopping criteria — which makes the comparison meaningless. The goal here was to hold everything constant except the architecture itself: the same 70/15/15 train/validation/test split, the same GloVe Twitter embeddings, the same early-stopping criterion, and consistent hyperparameters across all four models.
