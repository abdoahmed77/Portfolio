01 — Overview

Overview

This project collects hotel listing data from Booking.com across 17 Egyptian cities — 1,040+ listings in total — and builds a pipeline to clean, analyze, and model that data to predict nightly hotel prices in EGP.

02 — The Challenge

The challenge

Booking.com doesn't expose a public API for this kind of bulk listing data, so the first problem to solve was reliable collection: dynamically loaded content needed browser automation rather than a simple HTTP request. From there, real-world scraped data is messy — inconsistent formatting, missing fields, and outliers — which meant a proper cleaning and feature engineering stage was necessary before any modeling could be meaningful.

03 — Approach

Pipeline

Booking.com → Web Scraping → SQLite → Data Cleaning → Feature Engineering → EDA → Regression Models → Price Prediction

Data collection used Selenium to handle dynamically loaded pages and BeautifulSoup to parse listing details, with results stored in SQLite. Modeling compared seven regression approaches, including Lasso, XGBoost, and Random Forest, evaluated with Scikit-learn on top of a Pandas-based feature set.
